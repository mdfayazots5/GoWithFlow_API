PHASE 10: Cloudflare R2 Storage Integration — All File Uploads for Go With Flow

You are building Phase 10 of Go With Flow backend.
Assume Phases 1–9 are complete and working.
Use ALL standards from the System Context. Generate production-ready code.

This phase replaces all local wwwroot file storage with Cloudflare R2,
the permanent free-egress S3-compatible object storage layer for GoWithFlow.

R2 handles ALL file types in the platform:
  - Voice audio recordings (OGG/WAV) from live sessions
  - User avatar images (JPEG/PNG)
  - Admin-uploaded Excel script files (.xlsx)
  - Admin-generated report Excel exports (.xlsx)
  - Session report PDF/JSON exports (future-ready)

NO files are stored on the server disk after this phase.
wwwroot/avatars and wwwroot/uploads are deprecated.

==================================================
CLOUDFLARE R2 — BUCKET DESIGN
==================================================

Four buckets, one per file category:

  gwf-audio    → voice recordings
                 Key pattern: sessions/{sessionId}/turns/{turnIndex}/{userId}.ogg

  gwf-avatars  → user profile images
                 Key pattern: avatars/{userId}/{timestamp}.jpg

  gwf-scripts  → admin Excel uploads
                 Key pattern: scripts/{scriptId}/v{version}.xlsx

  gwf-exports  → generated report Excel files (admin export feature)
                 Key pattern: exports/{requestedByUserId}/{yyyyMMdd_HHmmss}.xlsx

All buckets are private. Files are never served via public URLs.
All access is via time-limited presigned URLs generated by the API.
Default presigned URL expiry: 60 minutes (configurable per file type).

4. APPLICATION LAYER — STORAGE SERVICE INTERFACE
==================================================

File: GoWithFlow.Application/Interfaces/Services/IStorageService.cs

  public interface IStorageService
  {
      /// <summary>
      /// Uploads a file stream to the specified bucket and key.
      /// Returns the storage key (not a URL) for saving in the database.
      /// </summary>
      Task<string> UploadAsync(
          Stream fileStream,
          string bucketName,
          string objectKey,
          string contentType,
          CancellationToken cancellationToken = default);

      /// <summary>
      /// Generates a time-limited presigned URL for a private object.
      /// Use this to serve files to the frontend — never expose raw R2 URLs.
      /// </summary>
      Task<string> GetPresignedUrlAsync(
          string bucketName,
          string objectKey,
          int expiryMinutes,
          CancellationToken cancellationToken = default);

      /// <summary>
      /// Soft-removes a file from R2.
      /// Call this when a user is deactivated or a script is soft-deleted.
      /// </summary>
      Task DeleteAsync(
          string bucketName,
          string objectKey,
          CancellationToken cancellationToken = default);

      /// <summary>
      /// Checks whether an object exists in the given bucket.
      /// Used for validation before generating presigned URLs.
      /// </summary>
      Task<bool> ExistsAsync(
          string bucketName,
          string objectKey,
          CancellationToken cancellationToken = default);
  }

5. APPLICATION LAYER — STORAGE KEY BUILDER
==================================================

File: GoWithFlow.Application/Helpers/StorageKeyBuilder.cs

  /// <summary>
  /// Centralizes all R2 object key construction for GoWithFlow.
  /// Always use this class — never build keys inline in services.
  /// </summary>
  public static class StorageKeyBuilder
  {
      public static string VoiceRecording(
          long sessionId, int turnIndex, long userId, string extension = "ogg")
          => $"sessions/{sessionId}/turns/{turnIndex}/{userId}.{extension}";

      public static string UserAvatar(long userId, string extension = "jpg")
          => $"avatars/{userId}/{DateTimeOffset.UtcNow.ToUnixTimeMilliseconds()}.{extension}";

      public static string ScriptExcel(long scriptId, int version)
          => $"scripts/{scriptId}/v{version}.xlsx";

      public static string ReportExport(long requestedByUserId)
          => $"exports/{requestedByUserId}/{DateTime.UtcNow:yyyyMMdd_HHmmss}.xlsx";
  }

6. APPLICATION LAYER — BUCKET NAME CONSTANTS
==================================================

File: GoWithFlow.Application/Constants/StorageBuckets.cs

  /// <summary>
  /// Use these constants everywhere a bucket name is needed.
  /// The actual bucket names are bound from CloudflareR2Settings at runtime.
  /// This enum is used to resolve the correct bucket from settings.
  /// </summary>
  public enum StorageBucket
  {
      Audio,
      Avatars,
      Scripts,
      Exports
  }

  /// <summary>
  /// Resolves a StorageBucket enum to the actual bucket name from settings.
  /// Inject IOptions<CloudflareR2Settings> and call Resolve().
  /// </summary>
  public static class BucketResolver
  {
      public static string Resolve(StorageBucket bucket, CloudflareR2Settings settings)
          => bucket switch
          {
              StorageBucket.Audio   => settings.Buckets.Audio,
              StorageBucket.Avatars => settings.Buckets.Avatars,
              StorageBucket.Scripts => settings.Buckets.Scripts,
              StorageBucket.Exports => settings.Buckets.Exports,
              _ => throw new ArgumentOutOfRangeException(nameof(bucket))
          };
  }

7. INFRASTRUCTURE LAYER — R2 STORAGE SERVICE IMPLEMENTATION
==================================================

File: GoWithFlow.Infrastructure/ExternalServices/CloudflareR2StorageService.cs

  @Injectable scoped
  Implements: IStorageService
  Uses: AWSSDK.S3 with AmazonS3Client configured for R2 endpoint
  Depends on: IOptions<CloudflareR2Settings>, ILogger<CloudflareR2StorageService>

  Constructor:
    - Read CloudflareR2Settings from IOptions
    - Build AmazonS3Client:
        new AmazonS3Client(
            accessKeyId,
            secretAccessKey,
            new AmazonS3Config {
                ServiceURL    = settings.AccountEndpoint,
                ForcePathStyle = true,
                SignatureVersion = "4"
            });

  UploadAsync implementation:
    - Build PutObjectRequest with BucketName, Key, InputStream, ContentType
    - Set UseChunkEncoding = false (required for R2 compatibility)
    - Await _s3.PutObjectAsync(request, cancellationToken)
    - Log upload: key, bucket, content-type via Serilog Information
    - On AmazonS3Exception: log Error, rethrow as StorageException
    - Return objectKey

  GetPresignedUrlAsync implementation:
    - Build GetPreSignedUrlRequest with BucketName, Key, Expires, Verb = GET
    - Return _s3.GetPreSignedURL(request) — synchronous, no await needed
    - Log presigned URL generated: key, bucket, expiry
    - Never log the actual URL (it contains credentials in the query string)

  DeleteAsync implementation:
    - Build DeleteObjectRequest with BucketName, Key
    - Await _s3.DeleteObjectAsync(request, cancellationToken)
    - Log deletion: key, bucket
    - Swallow AmazonS3Exception with 404 status (object already gone — not an error)
    - Rethrow all other exceptions

  ExistsAsync implementation:
    - Build GetObjectMetadataRequest with BucketName, Key
    - Await _s3.GetObjectMetadataAsync(request, cancellationToken)
    - Return true on success
    - Catch AmazonS3Exception with StatusCode 404 → return false
    - Rethrow all other exceptions

13. ANGULAR FRONTEND — USAGE PATTERN (for reference)
==================================================

No Angular code change is needed for the storage layer itself.
The API always returns presigned URLs as strings in the response.
Angular uses these URLs directly in <img src="...">, <a href="...">, etc.

Key rules for Angular services:

  - Avatar: bind [src]="user.avatarUrl" directly — it is already a presigned URL
  - Audio playback: <audio [src]="presignedAudioUrl" controls> — works natively
  - Excel download: window.open(presignedUrl) or <a [href]="presignedUrl">Download</a>
  - Never call R2 directly from Angular — always go through the .NET API

isDemo flag: when environment.isDemo = true, return dummy asset URLs
  (local assets or placeholder image URLs) instead of calling the API.
  No R2 calls are made in demo mode.
